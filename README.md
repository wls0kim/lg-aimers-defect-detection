# 디스플레이 공정 제품 이상 여부 판별

LG Aimers 5기 해커톤에서 디스플레이 제조 공정 자료로 불량 제품을 분류한 머신러닝 코드

## 개요

- 디스플레이 제조 공정 4단계(Dam, AutoClave, Fill1, Fill2)의 설비 측정값으로 제품의 정상, 불량 분류
- 불량 비율이 약 6%(정상 38,156개, 불량 2,350개)로 낮은 불균형 자료
- 기간: 2024.07 ~ 2024.08, 5인 팀

## 방법 설명

- **소프트 보팅**: 여러 모형이 낸 예측확률을 평균해 최종 분류를 정하는 앙상블 방법
- **분류 기준값 조정**: 불량이 드물 때 기본값 0.5 대신, 검증 자료에서 F1이 가장 높은 기준값으로 정상과 불량을 나누는 방법
- **PyCaret**: 여러 머신러닝 모형의 학습, 튜닝, 비교를 같은 절차로 묶어 주는 Python 라이브러리

## 자료

- LG Aimers 5기 대회 제공 자료 (공정별 설비 측정값, 대회 규정상 비공개)
- 실행 시 필요한 파일: `train.csv`, `test.csv`, `submission.csv`

## 분석 절차

1. **밀린 열 복구**: 일부 행에서 특정 변수부터 값이 한 칸씩 밀려 기록된 것을 확인하고 제자리로 이동
2. **인코딩**: 판정 변수(OK → 1, NG → 0), 장비 이름(#1 → 0, #2 → 1)
3. **변수 정리**: 공정 간 반복 기록된 식별 변수의 불일치 확인, 값이 하나뿐인 변수와 모든 값이 결측인 변수 제거
4. **탐색**: 공정별 변수 분포, 완전 상관 변수 쌍, 정상과 불량 집단의 분포 차이
5. **모형**: 변수 6개 선택, GBC, CatBoost, 랜덤 포레스트, LightGBM, XGBoost를 F1 기준으로 각각 튜닝한 뒤 소프트 보팅
6. **예측**: 검증 자료로 분류 기준값 선택, 공정 간 식별 변수 값이 다른 행은 불량으로 보정
